# Presets (Dimension Combinations + Complete CSS Composition)

> Maps all 17 presets from baoyu-slide-deck to their 4-dimension combinations.
> Each preset is a curated intersection of Texture x Mood x Typography x Density.
> Includes auto-select keywords, feel descriptions, best-use scenarios, and a guide to composing complete CSS.

---

## 4-Dimension Space

```
5 Textures x 7 Moods x 5 Typographies x 3 Densities = 525 possible combinations
```

The 17 presets below are the curated, battle-tested combinations. Custom dimension selection (via `--style custom`) allows any of the 525 combinations.

## Building Complete CSS from Dimensions

This section describes how to compose a complete `:root` CSS block by layering the four dimensions in order.

### Composition Order

```
1. TEXTURE   → set --bg-texture, --bg-overlay, --border-radius, --card-*
2. MOOD      → set all color variables (--bg-*, --text-*, --accent-*, --paper, --ink)
3. TYPOGRAPHY → set font families, --google-fonts-url, --headline-*, --body-*
4. DENSITY   → set spacing/sizing variables (--slide-padding, --*size, --*-gap)
```

### Composition Steps

#### Step 1: Start from Texture

Open the selected texture definition (e.g., `texture.md#grid`) and extract these CSS variables:

```css
:root {
  /* === TEXTURE: grid === */
  --texture: grid;
  --bg-texture: grid;
  --bg-overlay:
    linear-gradient(rgba(var(--ink-rgb), 0.03) 1px, transparent 1px),
    linear-gradient(90deg, rgba(var(--ink-rgb), 0.03) 1px, transparent 1px),
    linear-gradient(rgba(var(--ink-rgb), 0.06) 1px, transparent 1px),
    linear-gradient(90deg, rgba(var(--ink-rgb), 0.06) 1px, transparent 1px);
  --bg-overlay-size: 20px 20px, 20px 20px, 80px 80px, 80px 80px;
  --border-radius: 2px;
  --card-border-radius: 2px;
  --card-shadow: 0 1px 3px rgba(0, 0, 0, 0.06);
  --card-border: 1px solid rgba(var(--ink-rgb), 0.08);
  --shadow-intensity: 0;
}
```

**Important**: Texture variables referencing `var(--ink-rgb)` and `var(--paper-rgb)` work because those will be set in Step 2 (Mood). The `rgba()` syntax with RGB components requires the `-rgb` suffixed versions.

## Custom Dimension Selection

When a user selects "custom dimensions" (via Step 2 Round 2), the workflow:

1. Presents 4 dimension questions:
   - **Texture**: clean / grid / organic / pixel / paper
   - **Mood**: professional / warm / macaron / cool / vibrant / dark / neutral
   - **Typography**: geometric / humanist / handwritten / editorial / technical
   - **Density**: minimal / balanced / dense
2. Collects all 4 answers
3. Looks up each dimension's CSS block from the respective `dimensions/*.md` file
4. Composes the complete `:root` block using the 5-step process above
5. Labels the style as `custom: {texture}+{mood}+{typography}+{density}` (e.g., `custom: grid+professional+editorial+minimal`)

Custom styles reuse the same CSS variable naming as presets, so all HTML layout code works identically -- only the `:root` block changes.

## Theme Color Overlay (5 Presets from guizang-ppt-skill)

After composing the 4-dimension `:root` block, the theme color system (5 presets) can optionally override the slide background treatment for light/dark page alternation:

| Theme | Override Behavior |
|-------|-------------------|
| 墨水经典 (ink) | No override -- uses mood as-is |
| 靛蓝瓷 (indigo) | Shifts `--paper-tint` toward cool indigo, dark slides use deeper navy |
| 森林墨 (forest) | Shifts `--paper-tint` toward warm sage green, dark slides use deep forest |
| 牛皮纸 (kraft) | Overrides `--paper` to warm tan/brown, shifts whole palette earthy |
| 沙丘 (dune) | Shifts `--paper-tint` toward warm sand, dark slides use deep umber |

Theme overrides are applied as a second pass: first compose the full 4-dimension `:root` block, then selectively override `--paper-tint`, `--ink-tint`, and accent warmth/coolness based on the chosen theme.
